博客搭建完成，写第一篇博文验证整个流程。

这套博客是怎么工作的

  • 源码放在私有仓库 blog-source，里面是 Markdown 和配置
  • 每次 push 到 main，GitHub Action 自动执行 hexo clean && hexo generate
  • 生成的静态文件被推送到公开仓库 Rem-486-cyber.github.io
  • 访问 https://rem-486-cyber.github.io 就能看到最新内容

日常写文章的流程

push 之后等一两分钟，刷新博客就能看到新文章，不需要手动 hexo g -d。
